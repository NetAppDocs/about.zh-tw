= 開始使用 docs.netapp.com MCP 伺服器
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs:

[role="lead"]
將您的 AI 開發環境連接到 docs.netapp.com 模型上下文協定（MCP）伺服器。設定 MCP 伺服器後，您可以使用它來傳回源自 docs.netapp.com 上發布的技術產品文件的答案。



[[prerequisites]]
== 先決條件

在設定 docs.netapp.com MCP 伺服器之前，請先驗證下列事項：

* 您已檢閱 link:mcp-server-learn.html["了解 docs.netapp.com MCP 伺服器"] 中的需求與限制。
* 您可以存取受支援且符合 MCP 標準的用戶端，例如搭配 GitHub Copilot 的 Visual Studio Code、Claude Desktop、Cursor 或以 Python 為基礎的代理程式框架。
* 您必須擁有有效的訂閱金鑰。如果您未提供金鑰，MCP 請求將失敗並傳回存取錯誤。若要申請訂閱金鑰，請聯絡 ng-docs-mcp@netapp.com 並提供您使用案例的簡要執行摘要。
* 您擁有 docs.netapp.com MCP 端點的網路存取： `\https://docs.netapp.com/mcp`。

[[visual-studio-code-setup]]
=== Visual Studio Code 設定

您可以使用 GitHub Copilot 透過設定  `mcp.json` 檔案從 Visual Studio Code 連線到 MCP 伺服器。

.開始之前
* 此工作需要啟用 GitHub Copilot 擴充功能的 Visual Studio Code。


.步驟
. 在 Visual Studio Code 的專案工作區中，完成以下步驟：
+
.. 建立資料夾，命名為 `.vscode`
.. 在名為 `mcp.json`的資料夾中建立檔案


. 設定 `mcp.json`檔案。
+
[source, json]
----
{
  "servers": {
    "netapp-docs-mcp": {
      "type": "http",
      "url": "https://docs.netapp.com/mcp",
      "headers": {
        "Ocp-Apim-Subscription-Key": "${input:Ocp-Apim-Subscription-Key}"
      }
    }
  },
  "inputs": [
    {
      "type": "promptString",
      "id": "Ocp-Apim-Subscription-Key",
      "description": "Enter your access key",
      "password": true
    }
  ]
}
----
. 儲存檔案。
. （選用）設定全域存取。
+
若要在所有 Visual Studio Code 專案和工作區中設定 docs.netapp.com MCP 伺服器，請將組態新增至全域使用者設定目錄。

+
** *Windows*： `C:\Users\<your_username>\AppData\Roaming\Code\User\mcp.json`
** *macOS*： `~/Library/Application Support/Code/User/mcp.json`
+
新增伺服器定義：

+
[source, json]
----
{
  "servers": {
    "netapp-docs-mcp": {
      "type": "http",
      "url": "https://docs.netapp.com/mcp",
      "headers": {
        "Ocp-Apim-Subscription-Key": "${input:Ocp-Apim-Subscription-Key}"
      }
    }
  },
  "inputs": [
    {
      "type": "promptString",
      "id": "Ocp-Apim-Subscription-Key",
      "description": "Enter your access key",
      "password": true
    }
  ]
}
----
+

NOTE: 修改全域 `mcp.json`檔案後，重新啟動 Visual Studio Code 以套用組態。



. 驗證組態。
+
.. 在工作區中開啟 Visual Studio Code。
.. 確認  `.vscode/mcp.json` 檔案是否存在。
.. 使用 Copilot 提問。
+
.範例
_ONTAP 和 Cloud Volumes ONTAP 有什麼差別？_







[[claude-desktop-configuration]]
=== Claude Desktop 組態

若要將 docs.netapp.com MCP 伺服器註冊至 Claude Desktop，請更新 MCP 組態檔案：

* *macOS*： `~/Library/Application Support/Claude/claude_desktop_config.json`
* *Windows*： `%APPDATA%\Claude\claude_desktop_config.json`


[source, json]
----
{
  "mcpServers": {
    "netapp-docs-mcp": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://docs.netapp.com/mcp",
        "--header",
        "Ocp-Apim-Subscription-Key:${NETAPP_MCP_KEY}"
      ],
      "env": {
        "NETAPP_MCP_KEY": "paste-your-subscription-key-here"
      }
    }
  }
}
----


[[cursor-configuration]]
=== 游標組態

若要將 docs.netapp.com MCP 伺服器註冊到 Cursor，請更新 MCP 組態檔案。

若要全域套用此組態，請使用下列路徑：

* *Mac OS*： `~/.cursor/mcp.json`
* *Windows*： `%USERPROFILE%\.cursor\mcp.json`


若要在單一專案中套用組態，請在專案根目錄中使用  `.cursor/mcp.json`。


NOTE: 如果該檔案已設定其他 MCP 伺服器，請在現有的  `mcpServers` 物件內新增  `netapp-docs-mcp` （請務必在上一筆項目後方加上逗號）。如果沒有  `mcpServers` 鍵，請將該鍵新增至與任何其他設定並列的頂端層級。

[source, json]
----
{
  "mcpServers": {
    "netapp-docs-mcp": {
      "url": "https://docs.netapp.com/mcp",
      "headers": {
        "Ocp-Apim-Subscription-Key": "paste-your-subscription-key-here"
      }
    }
  }
}
----


[[python-ai-agent-integration]]
=== Python AI 代理程式整合

如果您正在建立直接呼叫 MCP 伺服器的應用程式或 AI 代理程式，請使用此選項。

您的用戶端連接到 MCP 端點並呼叫工具。

[source, python]
----
client = MCPClient("https://docs.netapp.com/mcp",
  headers={
          "Ocp-Apim-Subscription-Key": "<YOUR_API_KEY>"
      }
  )
response = client.call_tool("netapp_docs_ask", {
    "question": "What are ONTAP upgrade steps?"
})

----


[[use-the-docs-netapp-com-mcp-server]]
== 使用 docs.netapp.com MCP 伺服器

設定 MCP 伺服器後，您可以直接在首選的用戶端介面中與 NetApp 技術文件互動。

.關於此任務
* AI 用戶端會根據您的查詢選擇合適的工具來提供結果。
* 使用清晰、完整的問題，而不是簡短或模糊的查詢。
* 所有回應均以官方 NetApp 文件為依據。


.步驟
. 在您首選的 MCP 相容用戶端上開啟聊天。
. 呼叫已設定的 MCP 伺服器，並提出有關 NetApp 產品或程序的明確問題。
. 查看回應。
